# Proyectos de Packet Tracer

Prácticas y proyectos de redes hechos en Cisco Packet Tracer durante mi formación en Tecnologías de la Información e Innovación Digital (Universidad Politécnica de Sinaloa).

Cada carpeta contiene el archivo `.pkt` del proyecto. Para abrirlos necesitas Cisco Packet Tracer.

## Proyectos

### Enrutamiento
| Carpeta | Tema |
|---|---|
| `rip` | RIP |
| `eigrp` | EIGRP |
| `ospf-rip-static` | OSPF, RIP y rutas estáticas |
| `tres-protocolos` | Tres protocolos de enrutamiento |
| `integradora-rip-ospf-eigrp-static` | Integradora: RIP, OSPF, EIGRP y rutas estáticas |

### Switching
| Carpeta | Tema |
|---|---|
| `vlan-trunk` | VLAN y enlaces trunk |
| `vtp` | VTP |
| `spanning-tree` | Spanning Tree |
| `spanning-tree-sw` | Spanning Tree (switches) |

### Servicios y seguridad
| Carpeta | Tema |
|---|---|
| `dhcp-fijo` | DHCP |
| `acl` | ACL |
| `acl-dhcp-fijo` | ACL con DHCP |
| `ssh` | SSH |

### Voz
| Carpeta | Tema |
|---|---|
| `telefonia-voip` | Telefonía VoIP |
| `dial-peer-voip` | Dial peers VoIP |

### Redes inalámbricas
| Carpeta | Tema |
|---|---|
| `redes-inalambricas` | Redes inalámbricas |
| `wlc` | WLC (Wireless LAN Controller) |
| `integradora-wlc` | Integradora con WLC |

## Herramientas
Cisco Packet Tracer, Cisco IOS.
